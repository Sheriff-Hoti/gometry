3D wireframe — cheat sheet

Compressed essence of the 3D arc.

Convention (shapes/vec3.go)

X right, Y down-screen, Z away from the camera. Camera at the origin: visible means Z > 0.

Projection (Project)

px = cx + x·focal/z      py = cy + y·focal/z
z ≤ 0 → rejected (false); the edge is skipped

Doubling Z halves the offset from center. Bigger focal = bigger/flatter.

Rotation (RotateX, RotateY)

X:  y' = y·c − z·s      z' = y·s + z·c
Y:  x' = x·c + z·s      z' = −x·s + z·c     (c = cos a, s = sin a)

Applied X-then-Y, fixed in Vertices(). Quarter-turn checks: Y sends +X→−Z, X sends +Y→+Z.

Cube (shapes/cube.go)

8 vertices from index bits (bit 0 = X sign, 1 = Y, 2 = Z), rotated, translated to Center; 12 edges from cubeEdges; Lines() projects each edge, skipping rejected ones.

Spin (animations/spin.go)

RotX += dx;  RotY += dy;  wrap both mod 2π — every 100 ms tick

State lives in the closure (same pattern as the line animations); main.go uses Spin(0.06, 0.1): a Y-turn ≈ 6.3 s.

Full pipeline, one frame

Vertices → Project → Lines → Points → DrawHalf. Geometry, then screen.
