Bresenham line — cheat sheet

Compressed essence. If it's not here, re-read the lesson.

The loop (shapes/line.go Points())

dx = |Bx-Ax|        dy = -|By-Ay|      # dy is stored negative
sx = sign(Bx-Ax)     sy = sign(By-Ay)   # step direction per axis
err = dx + dy                           # the running error
x, y = Ax, Ay
loop:
  plot (x, y)
  stop if (x, y) == B
  e2 = 2 * err
  if e2 >= dy:  err += dy;  x += sx   # drifted enough in x: step x
  if e2 <= dx:  err += dx;  y += sy   # drifted enough in y: step y

Variable roles

NameMeaning
dx, dyAxis distances. dy is negative by construction.
sx, syDirection of travel per axis: −1, 0, or 1.
errHow far the true line has pulled away from the plotted cells, scaled to stay integral.
e22*err. Doubling avoids the ½ in "drifted more than half a cell".

Decision rules (shallow line: |dx| > |dy|)

TestMeaningAction
e2 >= dyAlways true here; x is the driving axisstep x every tick
e2 <= dxTrue line drifted ≥ half a cell in ystep y (diagonal move)

Mirror rules (steep line: |dy| > |dx|)

TestMeaningAction
e2 <= dxAlways true here; y is the driving axisstep y every tick
e2 >= dyTrue line drifted ≥ half a cell in xstep x (diagonal move)

Direction needs no rules at all: sx = sign(Bx−Ax) and sy = sign(By−Ay) are fixed before the loop, so reversed and negative-going lines run the identical loop. See lesson 2.

Edge cases

CaseWhy it works with no special-casing
Single point (A == B)The loop plots before checking the stop condition.
Pure vertical / horizontalsx (or sy) is 0, pinning that axis; the other drives every tick.
Off-screen pixelsPoints() takes no screen argument; Draw() skips out-of-bounds cells.

Reading a trace

Each plotted pixel is followed by the moves that leave it. A step that changes only x is a flat move; one that changes x and y is diagonal. Count the diagonal moves on a shallow line: there are exactly |By−Ay| of them.
